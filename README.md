# Дубль — Telegram Mini App

Мобильная игра на внимание: найдите единственный одинаковый символ на двух карточках.

## Локальный запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```powershell
npm start
```

## Публикация в Telegram

1. Разместите файлы на любом HTTPS-хостинге (например, GitHub Pages, Netlify или Vercel).
2. Создайте бота через `@BotFather`.
3. В BotFather выберите **Bot Settings → Menu Button → Configure menu button**.
4. Укажите HTTPS-адрес опубликованного приложения.

Для настоящей сетевой дуэли понадобятся сервер, комнаты и синхронизация игроков. Текущая версия включает режим на время и дуэль по очереди на одном телефоне.
